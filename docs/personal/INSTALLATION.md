# 安装与使用

## 加载已经构建的扩展

1. 在要使用个人版的 Chrome 资料中打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择 **`/Users/rick/Agent/read-frog-per/.output/chrome-mv3`**。macOS 的目录选择器可按 `⌘⇧G`，粘贴完整路径后回车。这个目录直接包含 `manifest.json`。
3. 核对卡片名称 **Read Frog Personal** 和 ID **`ihfgmajgigafdpkfldmikhmgkifhneff`**。在扩展菜单打开个人版设置，左侧有「本地笔记」。

官方商店版 ID 是 `modkelfkcfjpgbfmnbnllalkiogfofhb`。两者可以同时安装，各自的设置和数据库属于不同的扩展。两版在同一网页启用划词工具栏时可能各弹出一个工具栏。可以在不同 Chrome 资料分别使用，也可以只在一个版本中开启划词工具栏，然后刷新网页。全页翻译等功能也可以按同样方式分配。

## 配置自己的 AI 和第一条笔记

1. 打开设置 →「API 提供商」。添加或启用 OpenAI 或 Google Gemini，在这里填写自己的 API Key，选择账户可以使用的模型。使用服务商默认地址时可以留空 Base URL。
2. 在「自定义 AI 指令」从模板创建指令，或编辑已有指令。将提供商设为上一步的第三方服务，编辑提示词、图标、布局和所需的文本、数字或原选区字段。界面中的 Read Frog 内置模型是另外一项官方服务。
3. 在普通网页划词，运行指令。等结果显示后点击书签「保存到本地笔记」。首次写入会按该指令的字段建库，成功提示可直接打开目标库。
4. 如要用自己命名的列，在「本地笔记」新建笔记库并设置字段，在对应指令的「笔记库」页签选库、选择同类型的目标列，再点「保存映射」。可以让多条指令共用一个库。未映射的输出仍可在笔记详情的「原始 AI 输出」查看。变更曾映射字段的类型或删除字段后，请在此更新映射。
5. 在「本地笔记」点一条笔记，即可在当前标签页阅读全文。词语和释义、回复方式和正文、选题和角度会逐项排版。原始选中文字和来源在文章下方。「编辑笔记」可修改字段，「原始 AI 输出」可核对采集时的结果。「返回笔记库」回到原列表。也可以在笔记列表按住 ⌘（Windows/Linux 按 Ctrl）点击，在新标签页打开。删除笔记或整个库均需确认。

## 从官方版迁移

**设置和自定义 AI 指令。** 在官方版「偏好设置」的手动配置导出中选择「不包含 API Keys」。在个人版的相同页面导入文件。这个操作会替换个人版当前设置，导入前会自动备份原设置。早期格式通过上游配置迁移器逐版升级。个人版不接管官方库的账号绑定，导入后可让指令首次自动建库，或在「笔记库」页签连接本地库。

**个人版设置备份。** 从个人版导出的设置文件省略 API Key、自定义端点、请求头和服务商请求参数。迁移后在「API 提供商」补填需要的值。已有的官方导出文件若含自定义请求头或端点凭证，按私密文件保存。提示词、选中文字和笔记正文会随对应备份原样导出，请留意你自己写入这些文本的内容。

**官方云端笔记。** 在官方网站打开对应 Notebase 的 Notes 页签，清除搜索或筛选，选择 Export CSV。每个库单独导出一次。在个人版「本地笔记」选择「导入官方 CSV」，核对行数后确认。首行是字段名，列值按文本保存，文件名作为库名。导出表缺少的指令 ID、原始选区、来源、原创建日期和复习历史无法推回，导入时间作为本地创建时间。文件里已有的来源列仍作为文本保留。相同表格改名再导入会跳过，内容改变的导出会形成另一份独立库。[官方 CSV 导入导出说明](https://www.readfrog.app/en/docs/notebase/import-export)

## 完整备份和恢复

在「本地笔记」点「备份全部笔记库（JSON）」。它包含库、字段、笔记、原始结果、来源、时间和指令映射。换资料时可先导入设置，再点「恢复 JSON」核对数量并确认。同 ID 且内容相同会跳过，同 ID 内容不一致会取消整次导入并显示原因。需要保留两个历史版本时，可把另一份备份恢复到独立 Chrome 资料。「导出当前库 CSV」适合表格软件阅读，完整恢复请使用 JSON。

## 重新构建和升级

在项目根目录运行下列命令。仓库指定 pnpm 12.21.0、Node.js `^26.13.1` 和 WXT 0.21.5。本机通过 Corepack 和 pnpm 管理的 Node 完成构建。首次安装会下载锁定的依赖和运行时。

```sh
git switch personal
corepack pnpm install --frozen-lockfile
corepack pnpm build
```

个人 Chrome 构建直接使用仓库默认值，无需准备 `.env` 或输入服务商密钥。继续使用同一个 Chrome 资料、同一个目录和固定扩展 ID，在 `chrome://extensions` 点击个人版卡片上的「重新加载」，再刷新已有网页即可更新。卸载扩展或删除 Chrome 资料会清除它的本地数据，执行前请将 JSON 保存到该资料之外。上游版本更新步骤见[同步指南](UPSTREAM-SYNC.md)。
