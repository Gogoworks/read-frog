# Read Frog Personal

Read Frog Personal 供使用自己 OpenAI、Google Gemini 等服务商的读者在 Chrome 中划词、执行自定义 AI 指令，并把值得保留的结果存入当前浏览器资料。项目基于 Read Frog 1.62.1，沿用上游 GPLv3 许可证。

## 日常使用

1. 在「API 提供商」配置自己的服务，在「自定义 AI 指令」选定提供商和模型。指令继续使用原有模板、提示词、图标、结构化字段和结果布局。
2. 在网页选中文字并运行指令，点击结果卡原有的书签按钮。第一次保存会用指令名和输出字段建库。之后同一指令写入同一个库。翻译后的笔记建议可以勾选多项并一次保存。
3. 需要共用一个库或改变列名时，在指令的「笔记库」页签选择目标库，指定文本列和数值列的对应关系。在设置侧栏打开「本地笔记」即可管理内容。
4. 换浏览器资料或重装前，分别导出笔记 JSON 和设置 JSON。前者保存数据与字段映射，后者携带指令定义与偏好。

## MVP 功能与边界

| 需要 | 实现                                                                                                     |
| ---- | -------------------------------------------------------------------------------------------------------- |
| 收集 | 支持多个笔记库、单条与批量保存。写入与查询均在扩展内完成，容量取决于设备可用空间。                       |
| 追溯 | 保存原始选区、当时的指令名和结构化结果。来源可用时保留网页标题与链接、视频位置，或电子书标识与阅读位置。 |
| 整理 | 建库、改名、确认删库、浏览详情、编辑和确认删除笔记。可按内容及来源搜索，按创建时间升降序排列。           |
| 恢复 | 完整 JSON 备份可带回原库、笔记与指令关联。CSV 供表格软件阅读，也可以从官方导出的 CSV 建一个独立库。      |
| 界面 | 原有设置布局、弹窗、按钮、图标体系与深浅色主题。新增界面提供简体中文和英语，其他语言沿用上游的英语回退。 |

离线时可以保存已经显示的结果。生成新的 AI 结果需要所选模型可用。本期交付限于本机笔记。Drive 自动同步笔记、Supabase、多设备实时同步、独立闪卡与间隔复习、自动分类、向量检索、知识图谱及 MCP 留待后续。官方云端账号与服务继续遵循官方规则。
