# 个人版变更记录

## 2026-11-26 · 修复 Chrome 扩展管理器的脚本报错

- 打开设置、弹窗、侧边栏或翻译中心时，数据校验库 Zod 现在直接使用适合扩展的校验方式，解决 Chrome 记录 `Hash of blocked script` 的问题。

## 2026-11-26 · 已保存笔记的阅读页

- 将「原始选中文字」放在开头摘要下方，先看原文，再读重点、回复和选题。
- 点击笔记后，在当前标签页展开全文。重点按词语和释义排列，回复按方式分段，选题按标题和角度排列。其他模板按各自的字段和列表展示。
- 现有笔记直接使用阅读页，可在离线时刷新或用单条笔记链接打开。「编辑笔记」进入编辑模式，「返回笔记库」回到原列表。

## 2026-11-26 · 首个本地笔记 MVP

基础版本为 Read Frog 1.62.1，提交 `faebc639`。Chrome 扩展保留上游版本号，个人变更由本文件和 `personal` 分支的提交追踪。

- 以 Read Frog Personal 名称和固定独立 ID 构建可解压加载的 Chrome 扩展。
- 新增扩展私有的 Dexie 数据库、按指令自动建库、自定义字段映射及多库管理。在已有结果卡和批量笔记建议中接入本地保存。
- 新增设置页「本地笔记」，支持搜索、排序、查看来源、编辑、确认删除、完整 JSON 备份与合并恢复、导出 CSV 及导入官方笔记 CSV。
- 复用官方设置迁移器。个人版的手动设置导出、历史备份导出及恢复页导出过滤凭据。新增界面提供简体中文、英语与原生主题。
- 加入存储和迁移回归测试，以及在独立 Chrome for Testing 资料中运行的 OpenAI、Gemini、离线保存和浏览器重启验收。[测试记录](TESTING.md)
